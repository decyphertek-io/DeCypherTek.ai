# AppSec Reports

This folder stores security scan reports so AI agents can read the findings, fix them in the dev branch they were found on, and keep the scan → fix → rescan loop inside the repo.

## SonarQube

Generated by the "SonarQube Scan" workflow (`.github/workflows/sonarqube.yml`), which runs on manual dispatch (`workflow_dispatch`), scans the branch it is run from via SonarCloud, and pulls every open finding for that branch back into this folder:

- `sonarqube-issues.json` - machine-readable findings (latest state)
- `sonarqube-findings.txt` - readable summary (latest state)

Run the workflow from the branch you are working on (e.g. `dev-adminotaur` or `dev-usaginotsuki`) so the reports land where the fixes are made. After fixing findings, run the scan again to confirm the list shrinks.

The scan commits its report back to the same branch it ran on, tagged `[skip ci]` so it never triggers builds.
